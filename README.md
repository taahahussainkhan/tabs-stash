## ✨ Features

- **⚡ 1-Click Tab Stashing**: Stash all open tabs in under 50ms with a single click or keyboard shortcut (`Alt+S`).
- **💾 Massive RAM Savings**: Free up gigabytes of memory by converting heavy browser tabs into lightweight stashed records.
- **🖥️ Multi-PC Device Identity**: Automatically identifies the originating operating system (Windows, macOS, Linux), browser, and window ID with custom PC renaming.
- **📂 Flat "All Tabs" Master View**: View all stashed tabs without session boundaries, grouped dynamically by **Website / Domain**, **Date**, **Device**, or a **Flat List** with batch *"Open All"* actions.
- **📦 Protected Archive System**: Safe session archiving to keep your active workspace organized without risking data loss.
- **🔍 Multi-Criteria Filtering**: Filter across all sessions and tabs by site/domain (e.g. `instagram.com`, `github.com`), originating PC, and date range.
- **📐 Multi-Directional Card Resizing**: Drag the bottom-right corner (`///`), right edge, or bottom edge of any session card to freely customize its width and height independently.
- **🎨 Artistic Editorial Theme**: Matte charcoal surfaces, tactile terracotta accents, warm ochre pin badges, custom slim scrollbars, and zero distracting neon glows.
- **🌐 Universal Cross-Browser Compatibility**: Runs natively on **Chrome, Firefox, Microsoft Edge, Brave, and Safari**.

## 📥 Download & Installation

### Option 1: Direct Download (Pre-built Release)
1. Go to the [Releases](https://github.com/taahahussainkhan/tabs-stash/releases) page.
2. Download the zip for your browser:
   - **Chrome / Edge / Brave**: `tabvault-chrome-v2.0.0.zip`
   - **Mozilla Firefox**: `tabvault-firefox-v2.0.0.zip`
3. Extract the downloaded zip file to a folder.
4. Load into your browser:
   - **Google Chrome**: Go to `chrome://extensions/`, enable **Developer mode**, and click **Load unpacked**.
   - **Microsoft Edge**: Go to `edge://extensions/`, enable **Developer mode**, and click **Load unpacked**.
   - **Brave Browser**: Go to `brave://extensions/`, enable **Developer mode**, and click **Load unpacked**.
   - **Firefox**: Go to `about:debugging#/runtime/this-firefox` and click **Load Temporary Add-on...** (select `manifest.json`).

---

### Option 2: Clone from Source
```bash
git clone https://github.com/taahahussainkhan/tabs-stash.git
```
Then load the cloned folder into your browser as an unpacked extension.

## ⌨️ Keyboard Shortcuts

| Shortcut | Action |
| :--- | :--- |
| `Alt + S` | Stash all tabs in current window |
| `Enter` | Save session title edit |
| `Escape` | Cancel session title edit |
